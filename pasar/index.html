Shops on Pasar

Pasar reads each shop's public agent-manifest.json from its own website, like any agent would, and checks it against the open agentic web spec.

How it works

  1. Every shop owns its agent. Each shop is its own website with a published agent network (plain JSON) and its menu, rules and cart as tools.
  2. You ask once. The concierge decides which shops can help and asks each one. A card shows you the shop and the exact request first.
  3. Shops answer in your browser. The shop's network runs here, on your key. The shop never sees your key, your chat or your details.
  4. Prices are checked. Every price in the plan is compared with the shop's own published manifest, so a wrong number shows up.
  5. You order at the shop. "Order at …" opens the shop's page with the cart filled. The shop's assistant can finish the order with you.

Agentify your shop

Write your menu as a small JSON file and run the generator. You get a complete open agentic website: a shop page with cart and orders, an agent network, the public manifest and the browser runtime. Host it anywhere static, then add it to directory.json.

node generator/agentify-umkm.mjs catalogs/my_shop.json \
  --out sites/my_shop --page-url https://my-shop.example/
